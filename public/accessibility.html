Accessibility

Updated October 11, 2026

We aim to make Party Reveal easy to read and use. Visitors can browse candidates and cited sources without JavaScript. Search and filters require JavaScript.

Using the guide

The site provides headings, labeled search controls, keyboard navigation, and expandable race and source sections. Affiliation information appears in text, so color is not the only way to identify it.

Accessibility review

Checks include HTML validation, automated accessibility checks on expanded directory sections, and local keyboard search and mobile layout testing.

Automated checks do not establish complete accessibility or WCAG conformance. Full screen-reader testing and further manual checks for zoom, text spacing, touch targets, and other display settings remain to be completed.

Reporting a problem

If you have difficulty reading or using the guide, contact us below. Describe the page or action involved and, if possible, include your browser, device, and assistive technology. Let us know which information you were trying to find.
